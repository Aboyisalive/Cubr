# com.cubr.api - Kotlin client library for cubr API

Contract v0. Single source of truth between the Go backend and the
Kotlin (KMP) and TypeScript clients. Contract first: fragments that
touch the API change this file and regenerate clients before writing
server or client code.

Conventions:
- `CubeState.facelets` is the 54-sticker facelet string in URFDLB order
  (faces U, R, F, D, L, B; row-major within each face). Each character
  names the home face of that sticker's color.
- Errors are always the typed `ErrorResponse` shape.

## Build

First, create the gradle wrapper script:

```
gradle wrapper
```

Then, run:

```
./gradlew check assemble
```

This runs all tests and packages the library.
